# ADR-0001: 웹 앱 단일 플랫폼

- 상태: accepted
- 날짜: 2026-10-19
- 근거: 기능 명세 미결 사항 '플랫폼' → 웹앱

## 배경

데스크톱(Tauri/Electron)과 웹 중 플랫폼을 골라야 했다. 에이전트가 서버에서 도는지 로컬 사이드카로 도는지가 여기서 갈린다.

## 결정

웹 앱(SPA)만 만든다. 에이전트는 서버(Cloud Run)에서 돌고, dev에서만 로컬 서버 + 로컬 llama server를 쓴다.

## 결과

- 설치 없이 쓸 수 있고 배포가 단순하다.
- 로컬 파일 시스템·로컬 LLM은 prod에서 쓸 수 없다 (llama는 dev 전용).
- SQLite FTS5 같은 로컬 DB 대신 브라우저 기술을 써야 한다 (ADR-0004).
