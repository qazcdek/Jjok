# ADR-0004: 노트 검색: 브라우저 MiniSearch

- 상태: accepted
- 날짜: 2026-10-19
- 근거: 기능 명세 '노트 검색', 개발 계획 기술 스택

## 배경

기능 명세는 SQLite FTS5 + 임베딩 하이브리드를, 개발 계획은 웹 앱에 맞춰 브라우저 MiniSearch를 제안했다.

## 결정

v1은 브라우저 MiniSearch 키워드 인덱스. 인덱스는 IndexedDB에 캐시하고 동기화하지 않는다. 임베딩 검색은 v1.1.

## 결과

- 서버 없이 오프라인에서도 검색된다.
- 한국어 형태소 처리가 약하다 → 2-gram 보조 인덱스로 보완 (M3 검증).
- 기능 명세 문구(FTS5)는 다음 버전에서 수정 필요 (I-09).
