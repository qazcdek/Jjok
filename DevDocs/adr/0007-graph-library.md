# ADR-0007: 그래프 라이브러리: Cytoscape.js

- 상태: accepted
- 날짜: 2026-10-19
- 근거: 기능 명세 '리더와 그래프', 개발 계획 기술 스택

## 배경

논문 그래프와 노트 그래프에서 연결 기준별 스타일과 레이아웃을 바꿔야 한다. 후보는 Cytoscape.js, Sigma.js.

## 결정

Cytoscape.js를 쓴다. 엣지 계산은 Web Worker로 분리한다.

## 결과

- 스타일 시트·레이아웃 종류가 풍부하다.
- 노드 수천 개 이상에서 Canvas 렌더 성능이 떨어질 수 있다 → M7 성능 점검에서 기준 미달이면 Sigma.js 전환 검토 (그래프 데이터 계층은 라이브러리와 분리해 둔다).
