# ADR-0008: BYOK API 키: 서버 암호화, 클라이언트 읽기 불가

- 상태: accepted
- 날짜: 2026-10-19
- 근거: 기능 명세 7절 'API 키', DEV-004 §3

## 배경

사용자가 자기 LLM API 키를 입력한다. 키는 암호화해 저장하고 평문을 브라우저로 돌려주지 않아야 한다.

## 결정

- 키는 백엔드 서버에서 Cloud KMS로 암호화해 `users/{uid}/apiKeys/{provider}`에 저장. 클라이언트 규칙은 read/write 모두 거부.
- 표시용 마지막 4자리는 `users/{uid}/meta/llmKeys`(본인 읽기, 서버만 쓰기).
- dev는 같은 인터페이스의 로컬 키셋 구현.

## 결과

- 앱은 LLM 비용을 부담하지 않는다.
- 모든 LLM 호출이 서버를 거쳐야 한다 (브라우저 직접 호출 불가).
- KMS 비용·권한 관리가 생긴다.
