# 용어집

화면 문구, DevDocs, 테스트 이름, 코드 주석은 이 표의 **화면 용어**를 쓴다. 코드 식별자와 Firestore 필드는 영어 이름을 그대로 둔다.

상태: `확정`(화면·문서에 반영됨) · `제안`(해당 마일스톤 UI를 만들 때 확정).

## 1. 쓰는 원칙

- 연구자가 평소 쓰는 말을 쓴다. 영어 개념어를 한 글자 한자어로 옮기지 않는다 (예: Work → 작품, Version → 판 ✗).
- 영어가 더 익숙한 말(arXiv, PDF, BibTeX)은 그대로 쓴다. 다만 `venue`처럼 개발 용어는 화면에 노출하지 않는다.
- 버튼은 동작을 짧게 쓴다: "기본으로 지정", "버전 추가". "~를 수행합니다" 같은 번역투를 쓰지 않는다.
- 내부 구조를 드러내는 말(앵커, 노드, 엣지)은 화면에 쓰지 않는다.

## 2. 확정

| 화면 용어 | 코드 · 데이터 | 뜻 | 쓰지 않는 말 | 확정 |
| --- | --- | --- | --- | --- |
| 논문 | `Work`, `works/{workId}` | 같은 논문의 여러 버전을 묶는 단위. 라이브러리 목록의 한 줄 | 작품 | 2026-10-20 (H-003) |
| 버전 | `Version`, `versions/{versionId}` | arXiv v2, 학회 최종본, 저널 확장본처럼 논문의 개별 판본. PDF 파일 하나와 대응 | 판, 판본 | 2026-10-20 (H-003) |
| 기본 버전 | `primaryVersionId` | 논문을 열면 기본으로 열리는 버전. 버튼은 "기본으로 지정" | 대표 버전, 대표 판 | 2026-10-20 (H-003) |
| 라이브러리 | — | 사용자가 모은 논문 전체 | 서재 | 2026-10-20 |

## 3. 제안 (해당 마일스톤에서 확정)

| 제안 화면 용어 | 지금 문서 용어 | 코드 · 데이터 | 확정 시점 |

| 인용 키 | citeKey | `citeKey` | M1-11 |

| 링크 / 백링크 | 링크 / 백링크 (유지) | `links` | M2 |
