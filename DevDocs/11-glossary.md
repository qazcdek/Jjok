# 용어집

UserDocs, DevDocs, 화면 문구, 테스트 이름, 코드 주석은 이 표의 **화면 용어**를 쓴다. 코드 식별자와 Firestore 필드는 영어 이름을 그대로 둔다. 용어를 바꾸면 UserDocs·DevDocs·화면을 함께 고친다.

## 1. 쓰는 원칙

- 연구자가 평소 쓰는 말을 쓴다. 영어 개념어를 한 글자 한자어로 옮기지 않는다 (예: Work → 작품, Version → 판 ✗).
- 영어가 더 익숙한 말(arXiv, PDF, BibTeX, 핀)은 그대로 쓴다.
- 버튼은 동작을 짧게 쓴다: "기본으로 지정", "버전 추가", "핀 꽂기". "~를 수행합니다" 같은 번역투를 쓰지 않는다.
- 내부 구조를 드러내는 말(노드, 엣지, 앵커, venue)은 화면과 UserDocs에 쓰지 않는다. DevDocs의 기술 설명(데이터 모델, 그래프 계산, 선택자)에서는 쓸 수 있다.

## 2. 용어 (2026-10-20 확정, H-003)

### 라이브러리

| 화면 용어 | 코드 · 데이터 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- | --- |
| 라이브러리 | — | 사용자가 모은 논문 전체 | 서재 |
| 논문 | `Work`, `works/{workId}` | 같은 논문의 여러 버전을 묶는 단위. 라이브러리 목록의 한 줄 | 작품 |
| 버전 | `Version`, `versions/{versionId}` | arXiv v2, 학회 최종본, 저널 확장본처럼 논문의 개별 판본. PDF 파일 하나와 대응 | 판, 판본 |
| 기본 버전 | `primaryVersionId` | 논문을 열면 기본으로 열리는 버전. 버튼: "기본으로 지정" | 대표 버전 |
| 학회·저널 | `venue` | 논문이 실린 곳 (NeurIPS, ICLR, TPAMI …) | venue (화면) |
| 별칭 | `works.nickname` | 그래프에 제목 대신 보일 짧은 이름 | 닉네임 |
| 인용 키 | `citeKey` | BibTeX 키 (예: `vaswani2017attention`) | citeKey (화면) |

### 정리

| 화면 용어 | 코드 · 데이터 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- | --- |
| 분류 기준 | `axes/{axisId}` | 라이브러리를 나누는 관점. 직접 만드는 것(프로젝트, 연구 계보)과 자동으로 생기는 것(연도, 저자, 학회·저널)이 있다 | 축, 분류 축, 차원 |
| 컬렉션 | `collections/{collectionId}` | 분류 기준 안의 묶음. 한 논문은 분류 기준마다 다른 컬렉션에 동시에 들어갈 수 있다. 하위 컬렉션 가능 | — |
| 자동 분류 기준 | 계산값 | 연도 · 저자 · 학회·저널. 메타데이터로 계산하고 저장하지 않는다 | 자동 축 |
| 태그 | `tags` | 분류 기준과 별개인 가벼운 라벨 | — |

### 읽기 · 하이라이트

| 화면 용어 | 코드 · 데이터 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- | --- |
| 하이라이트 | `annotations/{annotationId}` | 텍스트 · 그림 영역 · 페이지 · 논문 전체에 남기는 표시 | 주석 |
| 메모 | `annotations.comment` | 하이라이트에 단 글 | 주석 메모 |
| 하이라이트 위치 | `anchor` (DevDocs: 앵커) | 하이라이트가 가리키는 곳. 화면에는 따로 이름을 붙이지 않는다 | 앵커 (화면) |
| 링크 / 백링크 | `links/{linkId}` | 하이라이트·논문·노트·URL 사이의 연결과 그 역방향 | — |
| 하이라이트 제안 | `createdBy: agent` | AI가 제안한 하이라이트. 수락하면 내 하이라이트가 된다 | 자동 주석 제안 |

### 그래프

| 화면 용어 | 코드 · 데이터 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- | --- |
| 논문 그래프 | 그래프 뷰 계산 | 논문을 점, 연결을 선으로 그린 그래프. 연결 기준을 바꿔 같은 논문들을 여러 그래프로 본다 | 계보 그래프, 연구 계보 그래프 |
| 노트 그래프 | — | 노트를 점, 위키 링크를 선으로 그린 그래프 | — |
| 연결 기준 | `edge kind` | 인용 · 공동 저자 · 같은 학회·저널 · 같은 노트 · 관계 | 엣지 기준 |
| 관계 | `links.type` | 사용자가 정하는 논문 사이 관계: 확장 · 반박 · 재현 · 관련 (+ 직접 추가) | 관계 유형 |
| 저장한 그래프 | `graphViews/{viewId}` | 연결 기준과 필터 조합을 저장한 것 | 그래프 뷰 |
| 핀 꽂은 논문 | `pinnedWorkIds` | 그래프에서 핀을 꽂은 논문. 제목이 보이고, 눌러서 리더에 열린 논문을 바꾼다. 브라우저 탭을 대신한다 | 활성 노드 |
| 핀 꽂기 / 핀 해제 | — | 탭 열기 / 닫기에 해당하는 동작. 핀을 해제하면 이름 없는 점으로 돌아간다 | 활성화 / 비활성화 |
| 라이브러리 밖 논문 | `citationCache` 교차 | 인용 관계로만 알려진, 라이브러리에 없는 논문 (선택 표시) | 유령 노드 |

### 노트 · 검색

| 화면 용어 | 코드 · 데이터 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- | --- |
| 노트 | `notes/{noteId}` | Markdown 노트 | — |
| AI 노트 | `notes.kind = ai_*` | AI가 만든 요약 · 키워드 · Q&A를 노트로 저장한 것 | AI 문서 |
| 템플릿 | `templates` | 노트 템플릿 | — |
| 노트 검색 | MiniSearch 인덱스 | 내 노트 · AI 노트 · 하이라이트 메모를 검색한다. PDF 본문은 검색하지 않는다 | 파생 문서 검색 |
| 검색 사이트 | `source` | 앱에서 논문을 검색하는 곳: arXiv, OpenReview, DBLP, ACL Anthology, CVF, Semantic Scholar, OpenAlex | 소스 |
