Jjok(이하 “서비스”)은 논문과 노트를 관리하는 웹 앱입니다. 서비스 운영자(이하 “운영자”)는 이용자의 개인정보를 「개인정보 보호법」 등 관련 법령에 따라 처리하며, 이 방침으로 어떤 정보를 왜 받고, 어디에 두고, 언제 지우는지 알려 드립니다.

2. Google 사용자 데이터

서비스는 Google OAuth로 다음 권한만 요청합니다: 기본 프로필(openid, email, profile)과 서비스가 만든 드라이브 파일에 대한 접근(drive.file).

  • Google에서 받은 정보는 위 1항의 목적에만 씁니다.
  • Google에서 받은 정보를 다른 이에게 넘기지 않습니다. 단, 이용자가 요청한 기능을 제공하는 데 필요한 경우(3항), 보안 목적, 법령상 의무가 있는 경우는 예외입니다.
  • 운영자가 이용자의 드라이브 파일 내용을 직접 열람하지 않습니다.
  • 서비스의 Google API 수신 정보 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

드라이브 접근 권한은 언제든 Google 계정의 타사 연결 관리에서 해제할 수 있습니다.

3. 이용자 요청에 따른 외부 전송

다음 전송은 이용자가 해당 기능을 실행할 때에만 일어납니다.

받는 곳 보내는 내용 언제
이용자가 고른 LLM 공급자: Google(Gemini), OpenAI(ChatGPT), Anthropic(Claude) AI 기능에 필요한 논문 본문·선택 영역·질문 텍스트. 이용자 본인의 API 키로 전송됩니다. 요약, Q&A, 주석·관계 제안 등 AI 기능 실행 시
학술 정보 서비스: arXiv, OpenReview, DBLP, Semantic Scholar, OpenAlex, Crossref 등 검색어, 논문 식별자(DOI, arXiv ID 등). 이용자 개인정보는 보내지 않습니다. 논문 검색, 메타데이터·인용 정보 조회 시

LLM 공급자로 보낸 내용은 해당 공급자의 정책에 따라 처리됩니다. 공급자가 API 데이터를 어떻게 보관·이용하는지는 각 공급자의 개인정보처리방침을 확인해 주세요. 공개 논문의 인용 정보는 이용자 간 공유되는 캐시에 저장될 수 있으나, 여기에는 누가 조회했는지 기록하지 않습니다.

4. 처리 위탁과 국외 이전

서비스는 운영을 위해 다음 업체의 클라우드 서비스를 씁니다.

수탁자 위탁 업무 이전 국가·위치
Google LLC 로그인(Firebase Authentication), 데이터 저장(Cloud Firestore), 웹 호스팅(Firebase Hosting), 서버 실행(Cloud Run), 키 암호화(Cloud KMS), 서버 로그(Cloud Logging), 사용 통계(Google Analytics) Firestore·서버 위치: 대한민국 서울(asia-northeast3) [데이터베이스 생성 후 확인]. Firebase Authentication·Hosting, Google Analytics 등 일부는 미국 등 Google 데이터센터에서 처리됩니다.

3항의 LLM 공급자 전송은 미국 등 해당 공급자의 서버로 이루어지는 국외 이전입니다. 이전 시점은 이용자가 AI 기능을 실행할 때, 방법은 암호화된 통신(HTTPS)입니다. 이 전송을 원하지 않으면 AI 기능을 쓰지 않거나 API 키를 등록하지 않으면 됩니다.

서비스는 쿠키를 광고 목적으로 쓰지 않습니다. 로그인 유지, 오프라인 사용, 화면 설정(예: 다크 모드), 내려받은 PDF의 임시 보관을 위해 이용자 브라우저의 저장소(IndexedDB, localStorage)를 씁니다. 사용 통계를 위해 Google Analytics가 쿠키(_ga 등)에 무작위 식별자를 저장합니다. 브라우저 설정에서 사이트 데이터를 지우면 함께 삭제됩니다.
